Android Publishing Guide (Google Play)

This app is built as a Single-File Offline-First Web App. To package it into an .aab / .apk for Google Play Store:

  1. CapacitorJS (Recommended): Place this HTML file inside www/index.html of a Capacitor project, run npx cap add android and build in Android Studio.
  2. PWABuilder / TWA: Host this file on GitHub Pages / Netlify / Vercel and use PWABuilder.com to generate a store-ready Google Play package.
  3. 100% Offline Ready: All club profiles, players, language preferences, and history are stored locally on the user's device.
